# Four Pillars of OOP — Python Programs

**Student:** Abdullah  
**Assignment:** Four programs for each OOP pillar; every program has at least 10 lines.  
**Total:** 16 independent Python 3 programs.

| Pillar | Programs | Main concept |
|---|---:|---|
| Encapsulation | 4 | Private data and controlled access |
| Inheritance | 4 | Parent and child classes, `super()` |
| Polymorphism | 4 | Same method name with behavior based on object |
| Abstraction | 4 | Abstract classes and required methods |

## Run

Install Python 3. From the repository directory, run any file, for example:

```bash
python encapsulation/01_bank_account.py
python inheritance/01_employee_manager.py
python polymorphism/01_animal_sounds.py
python abstraction/01_transport.py
```

On some systems use `python3` instead of `python`. Each file runs independently and prints a sample result. No external packages are needed.

4. Enter `Add 16 OOP pillar programs` and select **Commit changes**.
5. Open the repository link to check all four folders and 16 `.py` files appear, then share that link with Sir Saqib.
